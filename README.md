encountered проблемы:

1) При создании проекта командой
Flutter: New Application Project
VS Code выдаёт ошибку: «Flutter SDK not found».
Решение:
	скачать с flutter.dev и добавить путь к flutter/bin в переменную окружения PATH.
	В VS Code указать путь к SDK: Ctrl+Shift+P → Flutter: Change SDK.


2)При запуске проекта появляется ошибка: «No connected devices».

Решение:
	•	Запустить Android Emulator через Android Studio
