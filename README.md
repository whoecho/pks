ОТЧЕТ

1.	Какие виджеты использовались:
MaterialApp — для основного оформления приложения.</br>
	Scaffold — как основной каркас экрана (с AppBar и body).</br>
	AppBar — верхняя панель с заголовком.</br>
	Column — чтобы расположить элементы вертикально.</br>
	Text — для отображения значения счётчика.</br>
	Container — для обертки кнопок с цветным фоном и отступами.</br>
	ElevatedButton — для кнопок (увеличение и сброс).</br>
	SizedBox — для создания отступов между элементами.</br>
	Также использовались Padding и стилизация (TextStyle, Colors и т.д.).</br>
</br>
	2.	Как реализовано обновление состояния:
Я сделал экран как StatefulWidget, чтобы можно было изменять состояние.</br>
Счётчик хранится в переменной int counter внутри класса _PracticeScreenState.</br>
При изменении счётчика вызывается метод setState(), и Flutter перерисовывает экран с новым значением.</br>
</br>
	3.	Какие события обрабатывались:</br>
	onPressed у кнопки “Увеличить” — добавляет 1 к счётчику.</br>
	onLongPress у той же кнопки — добавляет сразу 10.</br>
	onPressed у кнопки “Сбросить” — сбрасывает счётчик в 0.</br>
