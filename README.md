**Были созданы 3 экрана:**
Приветственный экран
Экран со списком задач
Экран для добавления задачи

**Были использованы такие элементы интерфейса как:**
Текст
Кнопки
Список со скроллом
Поле для ввода

**Организация навигации:**
Навигация реализуется через пулл кнопок расположенных в нижней части экрана, кнопки делятся на два типа:
Кнопка “назад” - Возвращает на предыдущий экран
Кнопка “Перехода” - Переключает экран в зависимости от необходимости

**Краткий анализ: **
Удобно манипулировать роутами внутри режима prototype
Неудобно пользоваться гридом, интерфейс выглядит не интуитивно, также отсутствуют подсказки или мануал
